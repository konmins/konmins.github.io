隐私政策

扩展名称：AI 网页翻译：划词与整页双语对照　·　最后更新：2026-09-11

本扩展尊重并保护用户隐私。我们收集的数据范围如下：

1. 本地存储的数据

你配置的 API 接口地址、API 密钥、模型名、源语言与目标语言、术语表，以及侧边栏的翻译历史，仅保存在你的浏览器本地存储（chrome.storage.local）中。这些数据不会同步到云端、不会上传给开发者，你可以随时在设置页修改或清除，卸载扩展即完全删除。

2. 传输的数据

只有当你主动发起翻译时，你选中的文本、输入框内容或当前网页的可见文本才会被发送出去，且仅发送给你在设置中选择的那个翻译引擎：

  • Edge 免费引擎（默认）：微软 Edge 的公共翻译接口（edge.microsoft.com）。这是微软提供的公共服务，无需注册任何账号或密钥，相关处理遵循微软的隐私政策。
  • 自建大模型（可选）：你自己配置的大模型 API 端点（如 OpenAI、Google、Anthropic、DeepSeek，或你自建 / 本地运行的服务），使用你自己填写的接口地址与密钥。

以上内容均由对应服务按其自身的隐私政策处理，本扩展开发者无法访问。默认引擎不需要任何凭据即可使用；你可以随时在设置页切换到自己控制的端点，或改回默认引擎。

3. 不收集的内容

本扩展不收集姓名、邮箱、账号、广告标识符、地理位置等任何个人信息；不包含分析统计 SDK、广告 SDK 或任何形式的追踪代码；不会向开发者上报你的浏览记录或翻译内容。

4. 广告与赞助

当前版本的扩展界面中不包含任何广告或第三方赞助内容，也不会把你的任何数据发送给广告服务商，不存在需要退出的个性化广告设置。若未来版本引入赞助内容，我们会先更新本政策，说明向赞助商传输的数据类型与退出方式，并在扩展内提供关闭开关。

5. 自愿捐赠

本扩展所有功能完全免费，捐赠完全自愿，不会解锁任何功能，不捐赠也不会影响任何使用体验。若你在设置页或弹窗中看到「支持作者」入口，点击后只会在浏览器新标签页打开一个由开发者自行选择的第三方收款页面（如爱发电、Buy Me a Coffee、PayPal 等）：

  • 本扩展不提供任何支付表单，不收集、不处理、不存储你的支付账号、银行卡或交易信息；
  • 捐赠链接本身只保存在你本机浏览器中，可在设置页随时修改或关闭入口；
  • Microsoft 与 Google 既不参与收款，也不是本项目的筹款方、赞助方或背书方。任何捐赠相关的咨询、退款均请联系该第三方平台或开发者本人。

6. 第三方网站

本扩展在你访问的网页上运行以提供翻译功能，但不会修改页面内容以外的任何东西，也不会向开发者上报你访问了哪些网站。整页翻译时，代码块（pre / code 等）会被自动跳过，不参与翻译。

7. 权限说明

  • storage：保存你的配置与翻译历史到本地。
  • activeTab / tabs / scripting：在你点击工具栏按钮或右键菜单时，向当前页面注入翻译脚本。
  • contextMenus：提供右键菜单入口（翻译选中文本 / 整页 / 输入框）。
  • sidePanel：打开侧边栏翻译工作台。
  • 主机权限：默认仅用于访问 edge.microsoft.com（免费翻译接口）。其他大模型端点只在你自行填写并切换后才会被访问。

8. 联系我们

如对本政策有疑问，请通过 Microsoft Edge 加载项商店页面列出的开发者支持联系方式与我们联系。

Privacy Policy

Extension: AI 网页翻译 (AI Web Translator)　·　Last updated: 2026-09-11

1. Data stored locally

Your configured API base URL, API key, model name, source and target languages, glossary, and side-panel translation history are stored only in your browser's local storage (chrome.storage.local). They are never synced or uploaded, and are deleted when you uninstall the extension.

2. Data transmitted

Text is transmitted only when you actively trigger a translation, and only to the engine you selected in the options page:

  • Edge free engine (default): Microsoft Edge's public translation endpoint (edge.microsoft.com) — a public Microsoft service requiring no account or key, handled under Microsoft's privacy policy.
  • Your own LLM (optional): the API endpoint you configure yourself, using the base URL and key you provide.

The developer of this extension has no access to that data. You may switch engines at any time.

3. What we do not collect

We do not collect names, email addresses, account identifiers, advertising IDs, or location. The extension contains no analytics SDK, no ad SDK, and no tracking code, and never reports your browsing history or translated content to the developer.

4. Advertising

The current version displays no ads or third-party sponsored content, and sends no data to advertising services. If sponsored content is introduced in a future version, this policy will be updated beforehand to describe the data shared and how to opt out, and an in-extension toggle will be provided.

5. Voluntary donations

Every feature of this extension is completely free. Donations are purely voluntary, unlock nothing, and refusing to donate never degrades your experience. If you see a "Support the author" entry in the options page or popup, clicking it only opens, in a new browser tab, a third-party payment page chosen by the developer (e.g. Afdian, Buy Me a Coffee, PayPal):

  • The extension provides no payment form and does not collect, process or store any payment account, card or transaction data;
  • The donation link is stored only in your own browser and can be changed or hidden at any time in the options page;
  • Microsoft and Google are not involved in collecting donations and are not the fundraiser, sponsor or endorser of this project. Any donation question or refund request must be directed to that third-party platform or to the developer.

6. Contact

For questions about this policy, please use the developer support contact listed on the Microsoft Edge Add-ons store page.
